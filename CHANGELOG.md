# Changelog

Todos los cambios notables de este proyecto se documentan en este archivo.

## [0.1.0] - 2026-09-04

### ✨ Agregado
- **Servidor Node.js + Socket.IO** - Gestión de estado del juego multiplayer
- **Cliente Three.js** - Renderizado 3D en tiempo real
- **Sistema de Jugadores** - Creación, spawning y gestión de jugadores
- **Networking en Tiempo Real** - Sincronización de posiciones y eventos
- **Sistema de Daño Base** - Golpes, cuchillo y armas de fuego (sin aplicar aún)
- **5 Mapas Base** - Times Square, Mezquita Azul, Plaza Mayor, Castillo, La Boca
- **Cámaras FPS/TPS** - Cambio dinámico con tecla E
- **Chat en Tiempo Real** - Sistema de mensajes entre jugadores
- **HUD Base** - Mostra de salud, armas, jugadores vivos
- **Controlador de Jugador** - Movimiento WASD, mouse look, correr
- **Sistema de Personajes** - 12 personajes elegibles con estilos únicos
